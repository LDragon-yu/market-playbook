# 通过 Web 配置 API 与 Token

进入“数据与任务”，点击“打开配置面板”。当前支持配置：

- Tushare 或兼容代理的 Token、Base URL、积分档位；
- 大模型 API Key、Base URL、模型名和启用开关；
- Alpha Vantage、百度 OCR、OCR 模式与 AKShare；
- 盘中监控开关、轮询间隔和最大标的数。
- 飞书双向机器人启用开关、App ID / Secret、用户白名单及通知会话。

点击“保存并立即应用”后，服务器会原子更新项目根目录的 `.env`，并热加载行情源、大模型和监控器。若当时有一轮行情监控尚未结束，配置仍会保存，但页面会提示重启服务后生效。

本地默认保存到 `.env`；Docker Compose 保存到持久化卷中的 `data/runtime.env`，通过 `RUNTIME_ENV_PATH` 指定，容器重建后仍保留。同名运行 API 配置优先于基础环境变量。机器人配置修改后会重启长连接进程。登录认证仍在服务器基础 `.env` 配置，不能从页面修改。

## 密钥规则

- 已保存的密钥永远不会通过 API 返回到浏览器，页面只显示“已配置/未配置”。
- 密钥输入框留空表示保留原值；只有勾选对应的“清除”选项才会删除。
- 后端只接受预定义配置字段，不能通过页面写入任意环境变量。
- `.env` 仍是服务器上的明文秘密文件，不是密钥保险库。应用会尽力把文件权限设为仅当前用户可读写，但 Windows 和容器卷的实际权限仍取决于部署环境。
- 不要提交、截图、下载或备份分享 `.env`。
- 同样不要公开 `data/runtime.env`；它包含从 Web 保存的 API 密钥。镜像构建会排除密钥文件和数据目录。

## 公网部署前必须完成

首次登录账号不能通过这个页面设置。先在服务器 `.env` 手工配置：

```dotenv
APP_ENV=production
APP_USERNAME=你的登录名
APP_PASSWORD=足够长的随机密码
```

然后重启服务，并通过 HTTPS 访问。生产环境如果没有同时设置用户名和密码，后端会拒绝网页写入密钥；开发环境未认证时也只允许从 `localhost` 或 `127.0.0.1` 保存。配置接口还会拒绝跨站来源的保存请求。

如果服务器由多人管理，或需要更严格的审计、轮换和加密，后续应将秘密迁移到云厂商 Secret Manager、Docker/Kubernetes Secret 或 Vault；Web 页面只提交新值，不应承担密钥托管职责。
