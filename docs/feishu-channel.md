# 飞书：一个双向通道，手机和电脑均可使用

采用**企业自建应用机器人**，不是只能向群里发送消息的自定义 Webhook。接收事件使用飞书官方 Python SDK 长连接：本机或云服务器主动连接飞书，不需要公网回调 URL 或额外开放端口。网页和机器人使用同一份 SQLite 数据。

## 0. 快速清单（按顺序执行）

1. 飞书开放平台创建「企业自建应用」，添加「机器人」能力，记下 App ID / App Secret。
2. 权限管理申请 `im:message:send_as_bot`、`im:message.p2p_msg:readonly`（群聊再加 `im:message.group_at_msg:readonly`）。
3. 服务器安装依赖：`pip install -r requirements-feishu.txt`（Docker 镜像已包含）。
4. 在 `.env` 或 Web「数据与任务 → 飞书双向机器人」填入 App ID / Secret，`FEISHU_ENABLED=true`，保存。
5. 事件与回调选「使用长连接接收事件」，订阅 `im.message.receive_v1`，并发布应用版本。
6. 把机器人加进聊天，私聊发送 `/身份`，拿到自己的 `open_id` 和 `chat_id`。
7. 把 `open_id` 填入「允许用户」，`chat_id` 填入「通知目标」，再次保存。
8. 发送 `/帮助` 验证指令；在页面点「发送测试通知」验证推送。
9. 盘后任务跑完后检查是否收到复盘推送；再发 `/复盘`、`/预案` 读取。

若第 5 步之后机器人无响应，先确认应用已发布、自己在可用范围内、权限审批通过，再查 Web 上的长连接心跳状态。

## 1. 创建与配置

1. 到 [飞书开放平台](https://open.feishu.cn/app) 创建「企业自建应用」，添加「机器人」能力。你需要有创建应用的权限；所在组织若限制自建应用，请联系管理员。不要购买或共用他人的 App Secret。
2. 在「凭证与基础信息」取得 App ID、App Secret。
3. 在权限管理申请发送机器人消息 `im:message:send_as_bot`，接收单聊消息 `im:message.p2p_msg:readonly`；如果需要群内 @机器人，再申请 `im:message.group_at_msg:readonly`。以开放平台实际展示的权限名称及审批要求为准。不需要读取所有群消息、通讯录、交易账户或网盘。
4. 本地安装依赖：`python -m pip install -r requirements-feishu.txt`。Dockerfile 已包含安装步骤，旧镜像需要重新构建。
5. Web →「数据与任务」→「API 与 Token 配置」→「飞书双向机器人」：填 App ID、App Secret，打开启用开关，保存。密钥留空会保留现值，已保存密钥不回传前端。
6. 飞书「事件与回调」选择「使用长连接接收事件」，订阅「接收消息」`im.message.receive_v1`。首次平台可能要求先检测长连接，保持本项目运行。长连接建立并不代表事件已经订阅。
7. 创建版本、设置可用范围包含自己，并发布；完成组织要求的审批。将机器人添加到聊天，先私聊发送 `/身份`。
8. 将回复中的 `open_id` 填入 Web 的「允许用户」，将 `chat_id` 填入「通知目标」。多个用户使用英文逗号分隔。再次保存，然后发 `/帮助`。
9. 在「数据与任务」点击「发送测试通知」，检查飞书收件以及页面的发送状态。收不到时先检查应用是否发布、用户是否在可用范围内、权限是否通过和会话是否存在。

空白名单时不会查询、分析或修改任何用户数据；仅允许 `/身份` 返回请求者自己的 ID，不能自动绑定第一位来访者。机器人默认关闭。不要在聊天里发送行情 Token、LLM Key、账号密码。

## 2. 使用示例

```text
/持仓查看
/持仓 000592.SZ 总量=1000 可卖=1000 成本=10.5 买入=20260930
/确认 机器人返回的草稿编号
/问 000592.SZ 我的持仓今天应观察哪些失效条件？
/复盘
/预案
/文案 粘贴博主的完整观点或公告正文……
/材料 https://公开文章或视频地址
/字幕 机器人返回的素材编号 粘贴字幕/转写文本或文章正文……
```

持仓指令提供的是**该股全部持仓，不是增量**，数量单位是股。更新前必须核对总量、可卖量、成本及买入日期，再确认；10 分钟过期；草稿只能由原用户在原会话确认。已有股票会替换数值，但保留策略备注。已有持仓在草稿提交后发生变化时，确认会拒绝，要求重提。当天买入的这笔持仓可卖量必须为 0；同一股票多批次混合仓位请在 Web 中准确核对。清仓仍在 Web 手工处理。聊天内容、链接和模型不能触发券商交易。

目前问答需明确股票代码和后缀，不会猜测同名股票。模型未配置或失败时返回结构化事实和降级标记。问答展示行情时间；单次或少量股票快照不能证明整个板块的资金净流入、净流出，也不能保证交易成交或避免跌停风险。

## 3. 文案与视频的边界

- 文案和用户提供的字幕调用现有情报解析模块，来源与提交时间保留在情报库；事实和观点仍需核验。
- 公开 HTML 文章尝试读取可见正文；不执行网页脚本、不登录、不绕过付费墙或反爬。读取失败时返回素材编号，等待正文。抓取不保证准确提取所有网站的文章。
- 视频平台链接目前**不自动下载、观看或语音转写**，只收录为「待补充字幕」。发送 `/字幕 编号 文本` 后才分析。将来若接入获授权的字幕/ASR 来源，可复用同一素材流程。
- 获取正文成功后的分析结果进入 Web「情报中心」；链接处理进度在该页面的「飞书素材收件箱」展示。群聊必须 @机器人；群内回复对成员可见，涉及持仓建议私聊。
- 新情报用于**下一次生成**的盘前预案；现有冻结预案不会被自动事后改写。`/预案` 与 `/复盘` 只读取已有报告，不会自动运行耗时任务。问答会使用当前已录入持仓和最近情报。

## 4. 自动推送与复用接口

完成配置后，盘后复盘、盘前预案以及新增监控风险事件进入同一个飞书会话。监控需另外启用，通知不是行情源。风险通知有 90 秒发送期限，超时不会再发送；消息包含生成/失效时间，即使已送达也必须判断是否仍有效。复盘与盘前报告默认 12 小时发送期限，含报告日期和演示数据标记。

其他 agent 项目无需各自申请通知渠道，可调用本项目统一接口：

```python
import requests
import os

response = requests.post(
    "https://你的见势域名/api/notifications/send",
    auth=(os.environ["JIANSI_USER"], os.environ["JIANSI_PASSWORD"]),
    json={
        "source": "其他 Agent 项目",
        "title": "任务已完成",
        "body": "结果摘要或你自己的结果页面地址",
        "dedupe_key": "唯一任务编号",  # 同来源同编号不重复入队
        "ttl_seconds": 3600,
    }, timeout=15,
)
response.raise_for_status()
print(response.json())  # queued 表示入队，不代表已送达
```

收件目标由管理员固定配置，调用方不能指定任意用户/群。接口继承现有 Basic Auth，凭证有本项目管理权限，不能分享给不可信应用。未配置认证时只能从本机开发访问；公网必须在 `.env` 配置 `APP_USERNAME`、`APP_PASSWORD` 并启用 HTTPS。暂无独立的项目级 API Key、权限隔离或多 agent 入站路由；当前入站提问由股票项目处理，其他项目可复用出站通知。

## 5. 运行与安全

只运行一个 Web worker 和一个机器人进程（Uvicorn 不要使用多个 `--workers`；多实例不要共享同一数据目录）。主服务自动启动并监督子进程；官方 SDK 负责长连接重连。保存配置会重启机器人连接。CLI 定时任务只将通知入队，必须保持 Web 服务运行才能发送。

持久化 inbox/outbox 防止正常重复事件和重复入队；发送带稳定 UUID。网络故障最多重试 5 次，过期提醒不重发。崩溃时已在处理的请求标记为中断，**不自动重放**，避免重复持仓变更；请在 Web 核对结果后重提。极端网络故障下不能承诺 exactly-once 送达。

公开链接抓取会验证每次跳转和 DNS 解析结果，并固定连接到已验证公网 IP，阻止本机、内网、保留地址和云元数据访问。网页内容只作为分析材料，不是系统命令；不会因网页或博主文本修改持仓、密钥或执行交易。上游报错不回传可能含密钥的原始响应。

消息、持仓、链接和分析内容会存入本项目数据库；配置的飞书、大模型及行情服务可能分别接触相应数据。云服务器应限制访问，备份数据目录，避免把 `.env`、数据库或聊天记录上传公开仓库。

本地 Web 配置默认保存到项目 `.env`。Docker Compose 将 Web 修改保存在已挂载的 `data/runtime.env`，容器重建后仍保留，并覆盖启动时同名基础 API 配置；登录认证仍通过服务器基础 `.env` 配置。请一并备份 `data/runtime.env`，不要放入公开仓库。自定义部署可通过 `RUNTIME_ENV_PATH` 指定可持久化的运行配置文件。

官方参考：[长连接 SDK 示例](https://github.com/larksuite/oapi-sdk-python/blob/v2_main/samples/ws/sample.py)、[接收消息事件](https://open.feishu.cn/document/server-docs/im-v1/message/events/receive)、[发送消息 API](https://open.feishu.cn/document/server-docs/im-v1/message/create)。实际账号审批、可用权限和平台限制以控制台为准。
